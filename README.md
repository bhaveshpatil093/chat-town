# Chat Town

A TypeScript Node.js project scaffold.

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the app with `tsx` watch mode.
- `npm run build` compiles `src/` to `dist/`.
- `npm start` runs the compiled app.
- `npm test` runs the Node.js test suite through `tsx`.
- `npm run sim` starts the simulation entry point.
- `npm run lint` checks the code with ESLint.
- `npm run format` formats files with Prettier.
